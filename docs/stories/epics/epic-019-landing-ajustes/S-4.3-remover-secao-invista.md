**Epic:** EPIC-019
**Status:** Done
**executor:** @dev
**quality_gate:** @dev
**quality_gate_tools:** [tsc, build]

## Contexto

O dono do produto considera a seção "Invista no ramo imobiliário!" (título, texto "Usando
apenas seu CPF e um investimento mínimo de 5% do valor do imóvel, risco zero!", botão
"Quero investir nesse ramo" e os 3 cards — 100+ Casas / Garantia Total / Financiamento)
redundante com o resto do site, e pediu a remoção completa da Home.

## Acceptance Criteria

- [x] AC-01: a seção "Invista no ramo imobiliário!" (título, texto, botão e os 3 cards)
  foi removida inteiramente de `client/src/pages/Home.tsx`
- [x] AC-02: nenhum link/âncora do site (menu, botão "Ver Projetos" do hero, etc.) apontava
  para essa seção via scroll/hash — confirmado por busca (`href="#"`, `scrollIntoView`) em
  todo `client/src`; nenhum ajuste de redirecionamento foi necessário
- [x] AC-03: `tsc --noEmit` e `npm run build` passam limpos, sem imports não utilizados
  decorrentes da remoção (`Shield` do `lucide-react` removido do import da Home)

## Decisões de implementação (adaptações deliberadas, não invenção)

- Confirmado por busca em todo `client/src` que não existe nenhum `href="#..."` ou
  `scrollIntoView` apontando para esta seção — o botão "Ver Projetos" do hero e o CTA
  "Quero investir nesse ramo" (que estava dentro da própria seção removida) já apontavam
  para `/projetos-orcamentos`, uma rota própria, não um anchor de scroll. Portanto não há
  link quebrado a corrigir nem redirecionamento a criar.
- O import `Shield` (ícone usado só no card "Garantia Total" desta seção) foi removido de
  `Home.tsx` por não ter mais uso, evitando import morto.
