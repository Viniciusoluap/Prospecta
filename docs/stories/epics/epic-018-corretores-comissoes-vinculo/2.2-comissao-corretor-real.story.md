# Story 2.2 — Nova comissão: corretor dos cadastros reais

**Epic:** EPIC-018 · **Status:** InReview · **Executor:** @dev

## Investigação
O select "Corretor" já consultava `users.role = 'corretor'` (mesma fonte da tela Corretores), mas
era um campo opcional cujo primeiro item era "Não vinculado". No código não há caminho que esvazie
a lista quando há corretores cadastrados — **não foi possível confirmar, sem acesso aos dados de
produção, por que a lista apareceu vazia para o dono do produto**.

## Acceptance Criteria
- [x] AC-01: nova procedure `comissoes.formOptions` (corretores, imóveis, obras)
- [x] AC-02: para beneficiário "corretor", o campo é obrigatório com placeholder "Selecione o corretor"; sem corretores, mostra "Nenhum corretor cadastrado em Corretores"
- [x] AC-03: corretores inativos aparecem marcados "(inativo)"; para beneficiário "empresa" o campo some
