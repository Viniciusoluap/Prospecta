# Story 3.1 — Layout quebrado ao voltar para a Central Administrativa

**Epic:** EPIC-019 · **Status:** InReview · **Executor:** @dev

## Investigação (causa raiz encontrada por leitura de código)
1. Login de **admin** leva a `/admin` ("Painel Administrativo", `Admin.tsx`). Já o "Voltar" das
   telas que usam `OperationalPage` (Projetos, Comissões, Corretores, Mapa…) apontava para
   `/admin/acesso` — a "Central Administrativa" (`AdminAcesso.tsx`), tela que o admin nunca vê
   após o login. Sair e entrar de novo "conserta" porque o login volta para `/admin`.
2. `/admin/acesso` não estava na lista `hasPageBackButton`; o `GlobalBackButton` (fixo em
   `left-4 top-4`, `z-50`) era desenhado **por cima do título** "Central Administrativa".
3. O `Card` base aplica `text-card-foreground`, que no tema claro é quase preto; título e rótulos
   dos cards da Central não tinham cor própria → texto escuro sobre `#2C3E50`/`#1A2332`, ilegível.

Não houve reprodução em navegador nesta sessão (sem banco/credenciais); a correlação entre o
relato e o código é direta, mas a validação visual fica para o UAT.

## Acceptance Criteria
- [x] AC-01: `/admin/acesso` incluída em `hasPageBackButton` (sem botão global sobreposto)
- [x] AC-02: cores explícitas em título/rótulos da Central (`text-white`)
- [x] AC-03: "Voltar" das telas `OperationalPage` leva o admin para `/admin` e colaborador/corretor para `/admin/acesso`
- [x] AC-04: Central mostra link "Painel Administrativo" para admins
- [ ] AC-05: validação visual em produção (UAT do dono do produto)
